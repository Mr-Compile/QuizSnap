## Design Guidelines

### Style References
- **Quizlet:** Friendly, rounded, educational
- **Duolingo:** Playful, character-driven, encouraging
- **Notion:** Clean, minimalist, professional
- **Google Classroom:** Modern, trustworthy, organized
- **Anki:** Functional, focused on learning

### Key Principles
1. **Modern & Clean:** Flat design, minimal details
2. **Educational:** Flashcards, books, learning symbols
3. **Intelligent:** Lightning bolts, sparks, neural elements
4. **Trustworthy:** Professional, not childish
5. **Lightweight:** Not cluttered, easy to recognize
6. **Focused:** Emphasize studying and memory retention

### Technical Requirements
- All icons must be recognizable at 48×48 pixels
- Use safe zones for adaptive icons (central 66%)
- Transparent backgrounds for logos and overlays
- High resolution (1024×1024 for icons, 1080×1920 for screens)
- No text in launcher icons
- Strong contrast for accessibility

## File Naming Convention

After generating images, save them with these names:

```
assets/branding/
├── logo_light.png              # Horizontal logo for light theme
├── logo_dark.png               # Horizontal logo for dark theme
├── icon_light.png              # Main launcher icon (light bg)
├── icon_dark.png              # Main launcher icon (dark bg)
├── icon_foreground.png        # Adaptive icon foreground (transparent)
├── splash_light.png           # Splash screen (light theme)
├── splash_dark.png            # Splash screen (dark theme)
└── loading_logo.png           # Simplified logo for animations
```

## Integration Notes

1. **Icon Generation:** Use the prompts to generate all icon variants
2. **Testing:** Test icons on both light and dark backgrounds
3. **Adaptive Icons:** Ensure the foreground layer works with the green background
4. **Splash Screens:** Test fade-in animations with the splash assets
5. **Loading Animations:** Use the simplified logo for smooth pulse animations
6. **Consistency:** Maintain the same bamboo green (#16A34A) across all assets

## Next Steps

After generating images:
1. Place all PNG files in `assets/branding/`
2. Update `pubspec.yaml` with asset references
3. Configure `flutter_launcher_icons` in pubspec.yaml
4. Configure `flutter_native_splash` in pubspec.yaml
5. Run `flutter pub run flutter_launcher_icons`
6. Run `dart run flutter_native_splash:create`
7. Test on both light and dark themes
8. Verify adaptive icon behavior on Android
